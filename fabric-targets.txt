# Fabric build targets.
#
# The mod compiles once per line below and declares the whole range in
# fabric.mod.json, so a single jar covers every Minecraft version in it. This
# cuts the Fabric side from one project per release to one per API era.
#
#   <project> <compile-against> <covered minecraft versions...>
#
# The project directory is versions/<project> and <compile-against> is the
# oldest covered release, so the build files stay the ones that era needs. The
# fabric.mod.json predicate is derived as ">=<first> <=<last>".
#
# Membership is not cosmetic: every version in a line must share the mixin
# target. Verified against the intermediary mappings shipped by Fabric:
# SplashManager is net/minecraft/class_4008 and getSplash is method_18174 from
# 1.14.4 through 1.21.11, and SplashRenderer is net/minecraft/class_8519 from
# 1.20 through 1.21.11. The one thing that does change inside 1.20-1.21.11 is
# the SplashRenderer constructor (String becomes Component), and the reflective
# lookup in the modern mixin already covers both. Smoke test a jar before
# releasing it; a green build only proves it compiles.
