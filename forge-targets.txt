# Forge build targets.
#
#   <project> <compile-against> <covered minecraft versions...>
#
# The project directory is versions/<project> and it builds once, declaring the
# whole range in META-INF/mods.toml, so a single jar covers every release listed.
# <compile-against> is the oldest covered release, so the build files and the
# Java level stay the ones that era needs. Project names carry the loader suffix,
# matching the versions/<mc>-forge directories.
#
# Membership is a runtime claim. A Forge jar up to 1.20.4 ships a mixin refmap,
# so every version in a line must resolve getSplash to the same SRG name; the CI
# "report mixin refmap targets" step prints the name each jar bakes in. From
# 1.20.6 on there is no refmap at all, so the mixin resolves by literal name and
# the grouping is limited only by the build era.

# ForgeGradle 5, Gradle 7.6.4. Java 8.
1.16.1-forge	1.16.1	1.16.1 1.16.2 1.16.3 1.16.4 1.16.5
# ForgeGradle 5, Java 16.
1.17.1-forge	1.17.1	1.17.1
# ForgeGradle 5, Java 17.
1.18-forge	1.18	1.18 1.18.1 1.18.2
1.19-forge	1.19	1.19 1.19.1 1.19.2 1.19.3 1.19.4
# ForgeGradle 6, Gradle 8.13, Java 17.
1.20-forge	1.20	1.20 1.20.1 1.20.2 1.20.3 1.20.4
# ForgeGradle 7, Gradle 9.6.0, Java 21. No refmap, so no SRG constraint.
