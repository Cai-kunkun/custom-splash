# NeoForge build targets.
#
#   <project> <compile-against> <covered minecraft versions...>
#
# The project directory is versions/<project> and it builds once, declaring the
# whole range in META-INF/neoforge.mods.toml, so a single jar covers every
# release listed. <compile-against> is the oldest covered release. Project names
# carry the loader suffix, matching the versions/<mc>-neoforge directories.
#
# NeoForge mixin configs carry no refmap, so the mixin resolves getSplash by
# literal name and is independent of the Minecraft version. What limits a line
# here is the build era: the metadata format switched from classic to modern at
# 1.21.5, 1.20.5 still needs the legacy NeoGradle plugin, and the 26.x line uses
# a Java 25 toolchain.

# Legacy NeoGradle, classic neoforge.mods.toml, Gradle 9.6.0, Java 21.
1.20.5-neoforge	1.20.5	1.20.5
# ModDevGradle, classic metadata, Java 21.
1.21-neoforge	1.21	1.21 1.21.1 1.21.2 1.21.3 1.21.4
# ModDevGradle, modern metadata, Java 21.
1.21.5-neoforge	1.21.5	1.21.5 1.21.6 1.21.7 1.21.8 1.21.9 1.21.10 1.21.11
# ModDevGradle, modern metadata, Java 25 toolchain.
26.1-neoforge	26.1	26.1 26.1.1 26.1.2 26.2 26.3
